# 🌹 RISHTA24 (रिश्ता २४) — Official Product Information Website

Public informational and product presentation website for the **RISHTA24** matrimonial application.

## 🚀 Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom RISHTA24 Brand Theme Tokens
- **Routing**: React Router DOM (`react-router-dom` v7)
- **Animations**: Framer Motion (`framer-motion`)
- **Icons**: Lucide React (`lucide-react`)

## 🛣️ Public Routes
- `/` — Home / Landing Page
- `/features` — Complete Feature Showcase & Filter Tabs
- `/how-it-works` — 5-Step Matrimonial Workflow & 7-Vector Score Breakdown
- `/guide` — Step-by-Step User Manual & Screen Documentation
- `/about` — Product Vision & Philosophy
- `/faq` — Searchable Knowledge Base & FAQ Desk
- `/privacy-policy` — 16-Section Legal Privacy Policy with Sticky TOC
- `/terms` — 11-Section Terms of Use with Sticky TOC
- `/contact` — Support & Verification Desk
- `*` — 404 Error Page

## ⚡ Local Development
```bash
cd web
npm install
npm run dev
# Opens at http://localhost:5174
```

## 📦 Production Build
```bash
npm run build
```
